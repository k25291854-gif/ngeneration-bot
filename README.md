# 🚀 Generation Bot

Generation Bot is a Telegram bot that generates:

- 📧 Email names
- 👤 Usernames
- 💼 Business names
- ✨ Random names
- 💡 Creative ideas

## Deployment

This bot is designed to run on Railway using a GitHub repository.

## Environment Variable

The bot requires:

BOT_TOKEN

The Telegram bot token should be added privately in Railway.
